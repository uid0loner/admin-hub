quick tools 21

Small utilities, all on this page. Jump to one:

cidr-calculator

Enter an IPv4 address with prefix length and get network, broadcast, mask and host range. Want a visual map and a prefix slider? Try the full subnet calculator.

jwt-decoder

Paste a JSON Web Token to read its header and claims. Decoding happens in your browser; the signature is not verified.

hash-generator

Type or paste text to get its SHA-1, SHA-256, SHA-384 and SHA-512 hashes, computed locally in your browser.

password-generator

Random passwords from your browser's secure random generator. Nothing is stored or sent. Want to test an existing password instead? Try the password strength & crack-time estimator.



time-converter
Convert Unix seconds, Unix milliseconds, Windows FILETIME (Active Directory values such as lastLogon and pwdLastSet) or a date string.




base64-tool
Encode text as Base64, build a PowerShell -EncodedCommand string, or decode Base64 as UTF-8 and UTF-16LE to inspect encoded commands.





guid-generator
Random version 4 GUIDs, generated in your browser.









email-header-analyzer
Paste the full raw headers of an email to see the sender fields, SPF, DKIM and DMARC results and the delivery path. Processed locally.




port-reference
Common TCP and UDP ports for admins. Search by number, service or keyword.





regex-tester
Test a JavaScript regular expression against text and see matches and capture groups. Flags such as i, m and s are supported; g is always on.






json-formatter
Validate JSON and get a formatted and a minified version.




chmod-calculator
Set Linux file permissions with checkboxes or type an octal value such as 755.

url-encoder
Percent-encode or decode text for use in URLs.




cron-explainer
Enter a standard five-field cron expression, or a shortcut such as @daily, and see what each field means.





uac-decoder
Decode an Active Directory userAccountControl value, in decimal or hex, into its flags.




spf-explainer
Paste an SPF record (the TXT value) and get each part explained, including a count of DNS lookups.




dmarc-explainer
Paste a DMARC record (the TXT value of _dmarc) and see the policy, alignment and reporting settings.





markdown-previewer
Type or paste Markdown and see it rendered live. Supports headings, bold, italics, links, lists, code and tables.




text-diff
Compare two blocks of text line by line to see what changed, for example two config file versions.




case-converter
Convert text between camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE and Title Case.




ipv6-tool
Expand a shortened IPv6 address to its full form, or compress a full address to its shortest form.
