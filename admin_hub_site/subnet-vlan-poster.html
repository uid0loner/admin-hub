In your head: block size = 256 minus the interesting mask byte. /26 has mask .192, so blocks of 64: networks start at .0, .64, .128, .192. The first address of a block is the network, the last is the broadcast, everything between is for hosts.

VLANs in five lines

  • A VLAN is a separate switch inside the switch. Devices in different VLANs reach each other only through a router or firewall.
  • An access port belongs to one VLAN and sends plain frames: for PCs, printers, servers.
  • A trunk port carries several VLANs, each frame tagged with its VLAN number (802.1Q): between switches, to access points, to hypervisors.
  • The native VLAN of a trunk travels untagged. It must be the same on both ends, and should not be VLAN 1.
  • One VLAN, one subnet, one gateway. Write all three in the table below.
