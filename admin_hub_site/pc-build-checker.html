pc-build-checker

Seven parts from five makers, and one wrong millimetre sends a parcel back. Enter the parts list: the check compares socket, memory, sizes, clearances, plugs and power, draws the case to scale and says in plain words what does not fit and what is worth knowing before the first start.

Try:

where to find the numbers

NumberWhere it is written
Socket, memory type, M.2 slotsThe board's product page, under specifications. The memory type is also in the board's name on many models (a D4 or DDR4 suffix).
Graphics card length and thicknessThe card maker's page for the exact model. Two cards with the same chip differ by up to 10 cm.
Cooler heightThe cooler's data sheet, including the fan. If the fan sits above tall memory it adds a few millimetres.
Case limitsThe case's data sheet: "max. GPU length", "max. CPU cooler height", radiator positions. Read the footnotes: some limits apply only without front fans.
Power supply plugsThe cable list on the maker's page: count "PCIe 6+2 pin" plugs and look for "12V-2x6" or "12VHPWR".

The power figures are estimates of the peak draw by class, not measurements of your exact parts; the maker's recommendation for the graphics card overrules them. The check knows the common desktop platforms, not workstation sockets or small-form-factor specials.
