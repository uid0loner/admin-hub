linux-playground

web01 has had a bad morning: the shop is down, a disk is full and something odd sits in the uploads folder. You are the new admin. The server is pretend and runs in this tab, with about sixty real commands, pipes, redirects, sudo and file permissions. Eighteen missions take you from ls to finding out how the attacker got in.

anna@web01

Enter runs the line. Tab completes commands and file names once you have typed something; with an empty line it leaves the terminal as usual. Arrow up brings back earlier commands, Ctrl L clears the screen.

    This is a teaching model, not an emulator: the commands know their common options, not all of them, awk only prints fields, and there is no editor (use sed -i and echo >>). The output is modelled on Debian. What you type stays in this tab, and is replayed when you reload it.
