intune-analyzer

Drop the device list you export from Intune. You get one number for the health of the fleet, the devices behind every problem, what to do about each, and a command to pull the same list again later. The file is read by your browser and never uploaded, so it also works offline.

column mapping

Columns are matched by name. If your export uses different headers, point each field at the right column and the report re-runs.

getting the export

SourceHow
Intune admin centerDevices, All devices, Export. Choose to include all columns, not only the ones shown. The download is a zip with one CSV.
Microsoft Graph PowerShellGet-MgDeviceManagementManagedDevice -All | ConvertTo-Json -Depth 3 | Out-File devices.json (needs DeviceManagementManagedDevices.Read.All)

what it checks

CheckTriggers when
Jailbroken or rootedThe device reports a jailbreak or root.
Mail-only devices"Managed by" is Exchange ActiveSync only: the device syncs mail but gets no policy.
Non-compliantCompliance state is Noncompliant. High when it is 10% of the fleet or more.
No compliance verdictState is Not evaluated, Unknown, Error or similar. Usually no policy is assigned.
Grace periodThe device fails a setting but still counts as compliant until the grace period ends.
No disk encryptionEncrypted is false. High when Windows or macOS computers are among them.
Windows out of servicingThe build belongs to a feature update whose servicing has ended, by edition: Home/Pro and Enterprise/Education have different dates. Without an edition column the later date is used. Long-term servicing builds are judged by their own dates.
Old major versionsiOS/iPadOS, macOS or Android devices two or more major versions behind the newest one found in your own fleet. Needs at least five devices of the platform.
Android patch levelSecurity patch level older than 90 days.
Stale devicesNo check-in for more than 30 days, with a count of those over 90.
Duplicate recordsTwo or more records with the same serial number. Placeholder serials are ignored.
Personal devicesOwnership is Personal. Medium when Windows computers are among them.
No primary userThe primary user is empty.
Unsupervised Apple devicesCompany-owned iPhones and iPads that are not supervised.
Low storageLess than 10% of the storage is free.

"In good shape" means a device is compliant, encrypted, on a supported Windows version, seen in the last 30 days, not jailbroken and not mail-only. The export shows a state, not the reason: which compliance setting a device fails is only visible in Intune itself. Servicing dates for Windows are built into this page and were last reviewed in October 2026. If the newest check-in in the file is more than two weeks old, ages are measured from that day so an old export does not turn every device stale. Checks whose column is missing are listed as not checked.
