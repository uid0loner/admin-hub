bash-powershell-side-by-side

You know how to do it on one side and need it on the other. 105 everyday tasks, each in Bash and in PowerShell. Search by what you want to do, or by the command you already know: typing grep finds the PowerShell way, typing Get-ChildItem finds the Bash way.

the one difference that matters

Bash passes text from one command to the next, and you cut the piece you want out of each line with tools like grep, cut and awk. PowerShell passes objects with named properties, and you pick the property by name. That is why the Bash side is often shorter and the PowerShell side survives a changed column width. When a PowerShell line looks long, the reason is usually that it says what it means.

Bash commands follow GNU tools on Linux. macOS has BSD versions with slightly different switches. PowerShell lines work in Windows PowerShell 5.1 and PowerShell 7 unless the note says otherwise, and many of them work on Linux and macOS with PowerShell 7 too.
