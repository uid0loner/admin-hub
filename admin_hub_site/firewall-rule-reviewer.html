firewall-rule-reviewer

Firewall rule lists grow for years and nobody reads them from top to bottom. Drop yours here and see what is really open: remote administration and databases reachable from the internet, port ranges wider than anyone meant, rules that can never apply because an earlier one overrules them, and every rule rewritten as one plain sentence. The rules are read by your browser and never uploaded.

getting the rules

SourceHowNotes
Azure network security groupsaz network nsg list -o json > nsgs.jsonAll NSGs of the subscription in one file. A single NSG, a rule list or an exported ARM template work too.
Linux, iptablessudo iptables-save > rules.txtAlso reads the output of iptables -S. With nftables, iptables-save still works when the iptables-nft layer is installed.
Windows FirewallThe script below writes firewall.csv.Enabled inbound allow rules with their ports and addresses.
Any other firewallExport the rules as CSV, or build the table in a spreadsheet.The first line holds the column names. Needed: Action and Port or Source. Understood as well: Name, Direction, Destination, Protocol, Enabled, Priority, Group, Description. The row order counts as the rule order.

The Windows Firewall export. Run it in an elevated PowerShell on the machine, then drop firewall.csv above. It only reads.

Get-NetFirewallRule -Enabled True -Direction Inbound -Action Allow | ForEach-Object {
  $p = $_ | Get-NetFirewallPortFilter
  $a = $_ | Get-NetFirewallAddressFilter
  [pscustomobject]@{
    Name        = $_.DisplayName
    Direction   = $_.Direction
    Action      = $_.Action
    Enabled     = $_.Enabled
    Profile     = $_.Profile
    Protocol    = $p.Protocol
    LocalPort   = $p.LocalPort -join ','
    RemoteAddress = $a.RemoteAddress -join ','
    LocalAddress  = $a.LocalAddress -join ','
  }
} | Export-Csv firewall.csv -NoTypeInformation -Encoding UTF8

The page reads rules, it does not test the network. It cannot know what is attached behind a rule, whether a second firewall sits in front, or whether a port is really in use. Address groups, service objects and negated matches are compared by name only or left out, and IPv6 ranges are compared as text. Treat the result as a reading aid for a review, then confirm from outside, for example with the domain check or a port scan you are allowed to run.
