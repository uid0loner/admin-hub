event-id-reference

Common Windows event IDs for security and troubleshooting. Search by ID or keyword.

logon-types

The logon type in events 4624 and 4625 shows how a user signed in.

TypeNameMeaning
2InteractiveSigned in at the keyboard or console.
3NetworkAccess to a shared resource such as a file share, without an interactive session.
4BatchA scheduled task or batch job.
5ServiceA service started under an account.
7UnlockA locked workstation was unlocked.
8NetworkCleartextA network logon where the password was sent in clear text, for example basic authentication on IIS.
9NewCredentialsAlternate credentials for network connections, for example runas /netonly.
10RemoteInteractiveRemote Desktop or Terminal Services.
11CachedInteractiveLogon with cached domain credentials because no domain controller was reachable.

The list covers frequent events and is not complete. Availability depends on your audit policy and log settings.
