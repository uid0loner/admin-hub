powershell-playground

FS01 is a small company file server with a few problems: printing is down, memory is short, the disk is nearly full and somebody keeps guessing a password. You are the new admin. The PowerShell session is pretend and runs in this tab, with about fifty cmdlets and a real object pipeline. Twelve missions take you from Get-Command to a CSV report.

Administrator: PowerShell, FS01

Enter runs the line. Tab completes cmdlet names, parameters, property names and paths once you have typed something; with an empty line it leaves the terminal as usual. Arrow up brings back earlier commands, Ctrl L clears the screen. Upper and lower case do not matter.

    This is a teaching model, not PowerShell: the cmdlets know their common parameters, not all of them, there is no .NET behind the objects, no if, loops or functions, and no real system. The clock stands still at 6 October 2026, 08:30. Failed logon events carry the account as a ready-made property here; on a real server you dig it out of the event message. The short names work too: gsv, ps, ls, where, select, sort, group, measure, ft, fl, gm. What you type stays in this tab, and is replayed when you reload it.
