end-of-support watchlist

Tick the Microsoft products you run. The ones closest to end of support appear in the cockpit.

While "remember my results" is off, the tools store nothing and this page shows only what needs no data: the next Patch Tuesday and the newest exploited vulnerabilities. When it is on, each tool saves a short summary after you run it (the domain you checked, a grade, a count, the titles of findings), never the log file, the policies or any user names you analysed. The data sits in this browser's local storage: it does not sync to other devices, and clearing site data removes it.
