script-generator

Fill in the fields, get a ready-to-run script. Nothing you enter leaves your browser — these are built client-side from the templates below. Review every generated script before running it against production.

offboarding script

Generates a Microsoft Graph PowerShell script to offboard one user. Pick what it should do, then copy the result.




bulk user creation
Paste one user per line as Display Name,UPN,Password. Generates a Graph PowerShell loop that creates every account with a forced password change at next sign-in.








mailbox permission grant
Generates an Exchange Online PowerShell script granting mailbox access from one mailbox to another.
















conditional access policy
Builds the Graph PowerShell to create a Conditional Access policy. Test it in the simulator before deploying, and always create new policies in report-only mode first.


















tenant export for the analyzers
One read-only script that produces the two files the analyzers on this site take: your Conditional Access policies for the CA analyzer and your sign-in log for the sign-in analyzer. It changes nothing in the tenant.







Needs PowerShell 7 and the Microsoft.Graph module. Reading sign-in logs requires an Entra ID P1 or P2 licence and a role such as Security Reader or Reports Reader. The sign-in file contains user names and IP addresses: treat it as personal data, analyse it, then delete it. This script has not been run against your tenant by us, so read it before you run it.
