network-diagram-builder

The diagram every network should have and few do. Place devices, connect them, write names and addresses on them. The drawing is checked for loose ends and addresses used twice, and it lives in the link: copy it into your documentation, or save it as SVG or PNG. No account, nothing uploaded.

Start from:

a diagram people will read

  • Top to bottom, the way the traffic goes: internet, firewall, core, access, clients.
  • One box for "12 PCs" is better than twelve boxes. Draw single devices only where it matters which one: servers, switches, firewalls, access points.
  • Write on the links what the cable tester cannot tell you: VLAN, trunk, speed, which port.
  • Put the date in the title. A diagram without a date is assumed to be wrong.
  • Keep the link or the SVG where the next admin will look first, next to the IP plan.

The checks look at the drawing only, not at your network. Addresses in the examples are placeholders. The drawing is stored in the address of this page and nowhere else: bookmark it or copy the link to keep it.
